Política de Privacidad — aplicación «Hermes»

Última actualización: 4 de octubre de 2026

1. Qué es esta aplicación

«Hermes» es una aplicación de uso estrictamente personal, desarrollada y utilizada únicamente por su propietario, José Manuel Navarro García. Se ejecuta en un servidor privado propiedad del propio usuario y no está disponible para terceros: no existen otros usuarios, registros ni cuentas.

2. A qué datos accede y para qué

Con autorización expresa del propietario, la aplicación accede únicamente a los datos de su propia cuenta de Google, y solo para las siguientes finalidades:

  • Google Drive: leer y organizar los archivos del propio usuario (documentos, copias de seguridad, escaneos propios).
  • Google Fit: leer los datos de actividad del propio usuario (pasos, distancia, calorías, pulso, sueño) para llevar un registro personal de salud.
  • Google Books: consultar las estanterías de la biblioteca personal del usuario.
  • Google Calendar: crear y consultar eventos y recordatorios en el calendario del propio usuario.

La aplicación no accede a datos de ninguna otra persona ni a contenidos ajenos al propietario.

3. Con quién se comparten los datos

Con nadie. Los datos no se venden, no se ceden, no se alquilan ni se comparten con terceros. No hay publicidad, ni perfilado comercial, ni cesión a anunciantes o intermediarios. No se usan los datos para entrenar modelos de inteligencia artificial de terceros.

4. Dónde se almacenan

La información se procesa y almacena en el servidor privado del propio usuario (una máquina virtual contratada por él), accesible únicamente por el propietario. Los credenciales de acceso a las API de Google se guardan en ese mismo servidor con permisos restringidos y no se publican ni se comparten.

5. Conservación, revocación y supresión

El usuario puede revocar el acceso en cualquier momento desde su cuenta de Google (myaccount.google.com/permissions), y eliminar los datos borrando los archivos almacenados en su servidor. Al revocar el acceso, la aplicación deja de poder consultar los datos de Google de forma inmediata.

6. Uso limitado

El uso de la información recibida de las API de Google se ajusta a la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado (Limited Use): los datos se emplean exclusivamente para prestar las funciones descritas arriba, no se transfieren a terceros y no se utilizan con fines publicitarios.
